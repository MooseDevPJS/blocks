# Welcome to Blocks

Your notes are plain **Markdown** files in this folder: they are yours, forever.
The first line of each note is its title.

## What you can do
- [x] Write without thinking about saving: it's automatic
- [ ] Tick things off with a click
- [ ] Use **bold**, *italic*, ~~strikethrough~~ and `code`
- Link notes with double square brackets: [[Welcome]]
- Add links: [project site](https://github.com)
- Organize with tags: #ideas

## Photos and screenshots
- Copy a screenshot (Win+Shift+S) and press Ctrl+V in the note
- Or drag an image from File Explorer into the window
- Or right-click → Insert → Image from PC…

Images are copied into the `_allegati` folder, next to your notes.

## Right-click
Right-click the text for copy and paste, formatting, headings, lists,
inserting images and links, and file actions: pin, show in File Explorer,
copy path, move to the Recycle Bin.

> Markdown symbols only show on the line you are writing.

---

## Shortcuts
- Ctrl+K  search a note or a command
- Ctrl+N  new note
- Ctrl+B / Ctrl+I  bold / italic
- Ctrl+1 / Ctrl+2 / Ctrl+3  headings
- Ctrl+L  checklist, Ctrl+Enter to tick it
- Ctrl+\  show or hide folders
- Ctrl+Shift+\  focus mode
- Ctrl+click  opens links, notes and tags
