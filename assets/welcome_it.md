# Benvenuto in Yonote

Le tue note sono semplici file **Markdown** in questa cartella: sono tue, per sempre.
La prima riga di ogni nota è il suo titolo.

## Cosa puoi fare
- [x] Scrivere senza pensare al salvataggio: è automatico
- [ ] Spuntare le cose fatte con un clic
- [ ] Usare **grassetto**, *corsivo*, ~~barrato~~ e `codice`
- Collegare le note scrivendo due parentesi quadre: [[Benvenuto]]
- Aggiungere link: [sito del progetto](https://github.com)
- Organizzare con i tag: #idee

## Foto e screenshot
- Copia uno screenshot (Win+Shift+S) e premi Ctrl+V nella nota
- Oppure trascina un'immagine da Esplora file dentro la finestra
- Oppure tasto destro → Inserisci → Immagine dal PC…

Le immagini vengono copiate nella cartella `_allegati`, accanto alle note.

## Tasto destro
Con il tasto destro sul testo trovi copia e incolla, formato, titoli, elenchi,
inserimento di immagini e link, e le azioni sul file: fissa, mostra in Esplora file,
copia il percorso, sposta nel Cestino.

> I simboli Markdown compaiono solo sulla riga dove stai scrivendo.

---

## Scorciatoie
- Ctrl+K  cerca una nota o un comando
- Ctrl+N  nuova nota
- Ctrl+F / Ctrl+H  trova / sostituisci nella nota
- Ctrl+B / Ctrl+I  grassetto / corsivo
- Ctrl+1 / Ctrl+2 / Ctrl+3  titoli
- Ctrl+L  checklist, Ctrl+Invio per spuntarla
- Ctrl+\  mostra o nasconde le cartelle
- Ctrl+Shift+\  modalità concentrazione
- Ctrl+clic  apre link, note e tag
